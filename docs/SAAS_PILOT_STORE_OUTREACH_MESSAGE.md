# SaaS 파일럿 매장 섭외용 소개/연락 문안

작성일: 2026-06-04  
브랜치: `beta/staging-architecture`

## 1) 자전거 매장 사장님께 보내는 짧은 메시지

### 한국어
안녕하세요. 사장님, 안양의 왕웨이 자전거 매장 관리 SaaS를 새로 운영하는 팀입니다. 
매장 운영을 더 가볍게 할 수 있도록 `무료 파일럿`으로 먼저 직접 테스트해보실 수 있게 초대드립니다.

### 中文（繁體）
您好，店長您好。我們是 KINGWAY 自行車店管理系統團隊，想邀請您參加我們的新 SaaS 服務免費試用。 
先透過小規模實機試運行，幫您確認訂單、維修與 LINE 流程是否符合店務作業。

## 2) 시스템 소개

### 한국어
- 파일럿 전용 스테이징 기반 SaaS 데모
- 매장 생성부터 상품 등록, 주문/POS, 수리예약, 구매확인까지 한 번에 확인
- 매장 단위 데이터 분리 및 staff/owner 권한 분리 구조
- LINE 중심 운영(친구 추가, 예약/안내, 확인 흐름)을 지원

### 中文（繁體）
- 以示範環境提供的 SaaS 一站式體驗
- 從門市建立、商品上架、訂單/POS、維修預約、購買確認皆可完整展示
- 以門市為單位的資料隔離與權限控管
- 以 LINE 為核心的營運流程（預約通知、確認與回報）

## 3) 무료 파일럿 제안

### 한국어
현재 1차 파일럿을 무료로 진행하며, 실제 결제 이전에 운영 흐름을 먼저 점검하는 것이 목적입니다.
원하시면 사장님 영업 스타일에 맞춰 10분/30분 데모를 바로 진행해드리겠습니다.

### 中文（繁體）
目前提供第一輪「免費試用」方案，目的是在正式上線前先驗證是否符合店內流程。
可安排 10 分鐘或 30 分鐘的簡要示範，依貴店需求逐步調整。

## 4) 데모에서 보여줄 기능

### 한국어
- 매장 생성 및 owner 로그인
- 매장 설정(기본 정보/영업시간/표기)
- LINE 설정(민감정보 노출 없이 연결 상태 확인)
- 상품 등록
- 주문/POS 생성 및 조회
- 수리예약(접수→처리 흐름)
- 구매확인(토큰 기반 확인 흐름)
- Free/Premium 요금제 차이점(메뉴/권한)

### 中文（繁體）
- 門市建立與 owner 登入
- 門市基本設定（門市資料、營業時間、顯示）
- LINE 設定（不顯示機密資料的連線狀態驗證）
- 商品新增
- 訂單/POS 建立與查詢
- 維修預約（受理到處理）
- 購買確認（以 token 流程）
- Free 與 Premium 差異（功能與權限）

## 5) 부담 없는 피드백 요청

### 한국어
데모 후 불편한 점이 있다면 즉시 고쳐드리는 방향으로 반영 포인트만 간단히 남겨주시면 됩니다.
귀사 실무에 꼭 필요한 기능인지 기준으로 5~10분만에 정리해드릴 수 있습니다.

### 中文（繁體）
如果您覺得哪裡不順，請直接回覆您最在意的 1~2 點，我們會先針對現場實務需求做追蹤與調整。

## 6) LINE/전화로 약속 잡는 문구

### 한국어
편하신 시간(오늘/내일) 중 10분만 가능하신 시간 알려주시면, LINE 또는 전화로 일정 잡아 바로 데모를 진행하겠습니다.

### 中文（繁體）
請回覆您今天或明天方便的 10 分鐘時段，我們可用 LINE 或電話直接安排演示時間。

## 7) 발송 예시 문안

### 한국어
안녕하세요, 사장님. KINGWAY SaaS v1 파일럿 데모를 무료로 간단히 제안드립니다. 
매장 생성, 주문/POS, 수리예약, 구매확인, LINE 기반 운영을 10~30분 안에 확인해드리고, 부담 없는 조건으로 피드백만 받아 바로 반영하겠습니다.

연락: LINE 또는 전화(09:00~20:00, 평일/주말 모두 가능) 부탁드립니다.

### 中文（繁體）
您好，想邀請您參加 KINGWAY SaaS v1 的免費試運行示範。
我們將在 10~30 分鐘內示範門市建置、訂單/POS、維修預約、購買確認及 LINE 營運流程，並以最短回饋流程持續優化。

可透過 LINE 或電話聯繫（09:00-20:00，平日/週末皆可）。
