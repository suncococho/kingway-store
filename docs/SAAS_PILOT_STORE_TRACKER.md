# SaaS 파일럿 매장 운영 대장

- 대상: 파일럿 매장 5~20개 운영 추적
- 기준: 매장별 실사/데모/도입 진행 상태를 단일 문서에서 관리
- 상태(필수 값): `Contacted`, `Demo Scheduled`, `Demo Completed`, `Pilot Running`, `Converted`, `Rejected`

## 관리 항목
- 매장명
- 담당자
- 전화
- 지역
- 전기자전거 판매 비중
- 수리 비중
- 현재 사용 시스템
- 데모 여부
- 데모 일자
- 파일럿 시작일
- 파일럿 종료일
- 도입 의향
- 월 사용료 희망 가격
- 요청 기능
- 우선순위
- 상태
- 내부 메모

## KPI 요약

- 데모 수: 4개 (상태 `Demo Scheduled`, `Demo Completed`, `Pilot Running`, `Converted`)
- 파일럿 수: 2개 (상태 `Pilot Running`, `Converted`)
- 전환율: 50% (전환 1건 ÷ 파일럿 대상 2건)

---

## 업데이트 규칙
- 상태는 반드시 다음 6개 값만 사용: `Contacted` / `Demo Scheduled` / `Demo Completed` / `Pilot Running` / `Converted` / `Rejected`
- 20개 확장표는 신규 매장 추가 시 상단부터 순차 입력
- 전환율 계산식: `Converted / (Pilot Running + Converted)`
